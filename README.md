## 课程设计理念

这套课程关心的不只是“如何使用一个 AI 工具”，而是如何把人工智能用于具体的科研问题。课程沿着**科研智能体与科学模型两条主线**展开，再通过科研数据、工具调用和端到端工作流将两者联系起来。

- **从科研问题出发。** 先理解研究目标、数据条件和任务边界，再讨论适用的方法、模型与工具，避免为了使用 AI 而使用 AI。
- **先动手，再理解原理。** 通过可运行的案例建立直观认识，再解释数据处理、模型训练、知识库、记忆和智能体执行等关键环节。实操不是照着步骤操作，还需要理解每一步为什么这样做。
- **把 AI 融入科研过程。** 将编程智能体、科研工具和专业模型用于调研、分析、开发与验证，逐步从单项操作走向可以衔接的科研工作流。
- **重视验证与迁移。** 不把工具输出直接等同于科学结论；关注结果核验、可复现性和适用边界，帮助学习者将案例中的方法迁移到自己的研究问题。
